Add to Acme—release-notes

The only place you run a scan yourself. Everything aih ships is already scanned.

1Say exactly what it is

An exact version, never a branch. The email records who answers for this item. It is not a login.

2Scan it. You run this, aih does not install anything
aih skill vet acme/ai-skills --pin [commit] --name release-notes --apply
upload_fileDrop the result file here, or choose it

Other kinds get their own command: aih trust scan [owner/repo] --pin [commit] --apply for a repo, the matching trust scan for an npm MCP package. A remote MCP address cannot be scanned: aih records the exact address and who verified it, and labels it not scanned.
