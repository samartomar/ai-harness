How your team gets the same setup

1. Trim and save. The page downloads aih-project-policy.json. It records the policy it was cut from and never changes that policy.

2. Put it in the project folder and commit it.

3. Teammates clone the project and run the command they already use:

aih init . --apply

Nothing new to learn, nothing to point at, no account.

Where the organization policy comes from
Two files, never the same one

aih stops at the first one it finds. Try the other cases: project file · AIH_ORG_POLICY · nothing found

infoWhen aih runs, it checks the project file against the organization policy. Anything Acme no longer allows is trimmed, and you are told what and why. No one has to approve anything.
